ℹ️ About Country Blocking

How it works:
When a user visits the platform, their IP address is checked against a GEOIP database. If their country code matches any in the blocked list, access is denied.

Note: Local IPs (127.0.0.1, 192.168.x.x, 10.x.x.x) are never blocked.
